# Детектор резких звуков и SRP-PHAT

Прототип обнаруживает скачок энергии многоканального аудио и оценивает азимут
источника. Метку клаксона или тормозов он не присваивает: `sound_class` всегда
`unclassified`. Архитектура и ограничения описаны в Word документе.

## Запуск

Python 3.10+; единственная внешняя зависимость — NumPy.

```powershell
python -m pip install -r requirements.txt
python srp_phat.py array.wav --geometry geometry.json --out events.jsonl
python -m unittest discover -s . -v
```

Вход CLI: несжатый PCM16 WAV с частотой выше 16 кГц (рекомендуется 24 кГц),
минимум 3 синхронных канала. Координаты [x,y] в метрах должны соответствовать
порядку каналов; замените пример geometry.json координатами вашего массива.
Нужны неколлинеарные микрофоны. Код оценивает горизонтальный азимут в дальнем
поле: 0 градусов — +X, +90 — +Y. Высота и расстояние не оцениваются.

Извлечение дорожки с сохранением числа каналов (требует отдельного FFmpeg):

```powershell
ffmpeg -i input.mkv -map 0:a:0 -vn -ar 24000 -c:a pcm_s16le array.wav
```

Обычный моно/стереомикс не заменяет запись микрофонного массива.
Для привязки к видео задайте `--offset 1.25`, если первый отсчёт WAV
соответствует 1.25 секунды видео. PTS контейнера автоматически не читаются.

## Подключение потока

```python
from srp_phat import TriggeredLocalizer

engine = TriggeredLocalizer(positions, fs=24000, offset_s=0.0)
# В рабочем потоке для каждого последовательного блока:
event = engine.process(block)  # float PCM [480, M], обычно диапазон [-1, 1]
if event is not None:
    handle(event)
# Перед завершением:
last_event = engine.flush()
```

Сам захват, очередь, декодирование RTSP и наложение на видео относятся к
транспортному адаптеру и в этот комплект не входят. Не вызывайте process
из аудиоколбэка: локализация выполняется синхронно. При разрыве временной
шкалы пересоздайте обработчик с новым offset. На старте нужна секунда фона.

Порог 10 дБ над фоном и −45 dBFS, прогрев 1 с, предыстория 160 мс,
ожидание следующих блоков 220 мс, блокировка повторов 800 мс. Параметры
требуют настройки под микрофоны. Плавное нарастание и второй звук внутри
блокировки могут быть пропущены. Узкополосность, отражения и несколько
источников могут сделать направление неоднозначным. spatial_contrast —
диагностическая эвристика, не вероятность. Доказанного качества на реальной
дорожной сцене пока нет; тесты проверяют синтетические случаи.
